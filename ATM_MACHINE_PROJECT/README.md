# ATM MACHINE SYSTEM

## Introduction 
This is a Python made to creat a basic ATM  machine system. The program allows the user to creat an account sign in, deposite and Gmail ID , change ATM PIN and check account balance.

## Features 
1. creat an account
2. Sign in using acount number and ATM PIN 
3. Deposite money
4. Withdraw monay
5. Add moblile number 
6. Add Gmail ID
7. Change ATM PIN 
8. change bank balance 
9. Print statement receipt 
10. Exite the system 

##  ATM Operations 
The program provides different ATM oprations after creating an account or signing in.

~ Deposite money into account 
~ Withdraw money from account 
~ Check current  balance 
~ Change ATM PIN 
~ Add mobile number 
~ Add Gmail ID 
~ statement reciept option
