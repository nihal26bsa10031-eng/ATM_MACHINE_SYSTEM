# STUDENRT MANAGEMENT SYSTEM 

## PROBLEM STATEMENT 
This is a Python project that can be used to manage student records from the terminal.

If a user wants to store and manage basic student information, this program provides simple options to add, view, search, and delete student records.

## OBJECTIVE 

The main objective of this project is to create a simple student record management system using Python functions, lists, and dictionaries.

## INFORMATION STOREd
The program stores:
1. Roll number 
2. Student name 
3. age
4. Course 

## Main Operariona

### Add student 
The user can enter the student's roll number, name, age, and course. The details are stored in the student list.

### View Students
This option displays all the student records stored in the program.

### Search Student
The user can enter a roll number to search for a particular student. If the roll number is found, the student's details are displayed.

### Delete Student
The user can enter a roll number to delete a student record from the list.

### Exit
This option closes the Student Management System.

## Program structure 

The program is divided into different functions. Each function performs a specific task.
The main() function displays the menu and calls other functions according to the user's choice.
Student information is stored in a list named students. Each student is stored as a dictionary.

## Python concepts used 
1. variable
2. Input and output 
3. lists
4. dictionaries
5. Functions
6. if-else 
7. loops
8. list methods 

## conclution

The Student Management System is a basic Python project for managing student records. It provides a simple way to add, display, search, and delete student information through the terminal.
