
# STUDENT MANAGEMENT SYSTEM 

## INTRODUCTION

This is a Python project made to manage student records from the terminal.
The program allows the user to add student details like roll number, name, age, and course. The user can also view, search, and delete student records.

## Features

1. Add Student
2. View Students
3. Search Student
4. Delete Student
5. Exit the program

## Student Details 
The program stores the following 
details.
1. roll number 
2. student name 
3. age 
4. course 

## HOW THE WORK 
When the program starts, it shows the Student Management System menu.
The user can select an option by entering a number.

Option 1 : is used to add a new student.
Option 2 : is used to display all student records.
Option 3 : is used to search a student using the roll number.
Option 4 : is used to delete a student using the roll number.
Option 5 : is used to exit the program.

## Data Storage
Student records are stored in a python containing:

1. roll_no
2. name
3. Age
4. course

## Funtions used 
The project uses different funtions for different tasks :

1. add_student()
2. view_student()
3. search_student()
4. delete_student()
5. main() Controls the main menu and program flow. 


## Conclution 

This project is a simple Student Management System made using Python. It helps to perform basic operations on student records such as adding, viewing, searching, and deleting students.
